HackFresh — Resume ATS Score Checker & Resume Maker

About the Project

HackFresh is a web application designed to help users check their resumes for Applicant Tracking System (ATS) compatibility and create professional resumes.

Features
- Resume ATS score checking
- Resume creation and editing
- User-friendly interface
- Resume analysis and feedback, where implemented

Tech Stack
- Next.js
- React
- TypeScript
- Supabase, if configured
- CSS / Tailwind CSS, depending on the implementation

Getting Started

Prerequisites
- Node.js
- npm
- Git

Installation
Clone the repository:
git clone YOUR_GITHUB_REPOSITORY_URL

Open the project directory:
cd hackfresh

Install dependencies:
npm install

Create a ".env.local" file containing the environment variables required by the application. Use your own credentials and never upload this file to GitHub.

Start the development server:
npm run dev

Open http://localhost:3000 in your browser.
Environment Variables

Configure the required environment variables locally. Refer to ".env.example" if provided.
